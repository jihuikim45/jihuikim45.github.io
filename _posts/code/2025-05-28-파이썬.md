## 변수 NAME_SPACE

변수가 최초로 정의된 영역에 따른 유효 범위가 결정된다.

1. - **지역변수 (Local Variable)**  
     함수나 블록 내부에서 정의된 변수이다.  
     _해당 함수 안에서만 유효하며, 함수가 끝나면 사라짐_

1. - **전역변수 (Global Variable)**  
     함수 밖에서 정의된 변수이다.  
     _프로그램 전체에서 접근 가능, 단 함수 안에서 수정하려면 global 키워드 필요_

1. - **정적변수 (Static Variable)** :  
     함수가 여러 번 호출되어도 값이 유지되는 변수이다.  
     파이썬에는 직접적인 static 키워드는 없지만,
     _함수 속성이나 클래스 변수로 "정적 변수처럼" 동작하게 할 수 있음_

### 1. 지역 변수

```python

def local_example():          #def: define의 줄임말로, 함수 정의 시 사용
    local_var = 100
    print('여기는 함수의 영역입니다.', local_var)
    return local_var         # 함수 바깥으로 값 전달

local_var = local_example()  # 함수 호출 후 결과를 변수에 저장
print(local_var)  # 100

```

> 결과값:  
> 여기는 함수의 영역입니다. 100  
> 100

### 2. 전역 변수

```python

var_test = '나는 전역이다'
print(var_test)

def global_example():
    global var_test
    var_test = 100
    print('여기는 함수의 영역입니다.', var_test)
    return var_test  # 올바른 전역 변수 반환

global_example()

print(var_test)

```

> 결과값 :  
> 나는 전역이다  
> 여기는 함수의 영역입니다. 100  
> 100

### 3. 정적 변수

```python

def counter():
    if not hasattr(counter, "count"):
        #※ hasattr(...) 처음 한 번만 count = 0을 실행하게 함
        counter.count = 0  # 딱 한 번만 실행
    counter.count += 1
    print(counter.count)

counter()  # 1
counter()  # 2
counter()  # 3

```

> 결과값:  
> 1  
> 2  
> 3

### 4. 클래스 변수

```python

class Counter:
    count = 0  # 클래스 변수: 모든 인스턴스가 공유

    def increment(self):
        Counter.count += 1
        print(Counter.count)

c1 = Counter()
c1.increment()  # 1
c2 = Counter()
c2.increment()  # 2

```

> 결과값:  
> 1  
> 2

## 파이썬의 자료형

| 분류            | 자료형  | 설명                                 | 예시                               |
| --------------- | ------- | ------------------------------------ | ---------------------------------- |
| **기본 자료형** | `int`   | 정수형                               | `10`, `-5`, `0`                    |
|                 | `float` | 실수형                               | `3.14`, `-0.1`, `2.0`              |
|                 | `bool`  | 불리언 (참/거짓)                     | `True`, `False`                    |
|                 | `str`   | 문자열                               | `'hello'`, `"Python"`              |
| **복합 자료형** | `list`  | 리스트 (여러 값을 순서 있게 저장)    | `[1, 2, 3]`, `['a', 'b', 'c']`     |
|                 | `tuple` | 튜플 (리스트와 유사하지만 변경 불가) | `(1, 2)`, `('x', 'y')`             |
|                 | `dict`  | 딕셔너리 (키-값 쌍)                  | `{'name': '지희', 'age': 25}`      |
|                 | `set`   | 집합 (중복 없는 값들의 모음)         | `{1, 2, 3}`, `{'apple', 'banana'}` |

**예시**

```python
type(3)         # <class 'int'>
type([1, 2, 3]) # <class 'list'>
```

> list, tuple, dict, set 모두 내장형 객체로,  
> 기본 자료형을 조합해서 만든다는 의미에서 "복합 자료형"이라고 불린다.  
> type() 함수를 사용하면 어떤 자료형인지 확인할 수 있다.

## 불변형과 가변형

| 구분       | 자료형  | 값 변경 가능 여부 | 예시                                 | 비고                              |
| ---------- | ------- | ----------------- | ------------------------------------ | --------------------------------- |
| **불변형** | `int`   | 불변              | `a = 3`; `a = a + 1` ➡️ 새 객체 참조 | 정수는 새 객체 생성됨             |
|            | `float` | 불변              | `b = 3.14`                           | 실수형은 불변                     |
|            | `bool`  | 불변              | `flag = True`                        | 불리언도 불변                     |
|            | `str`   | 불변              | `"hello" + "world"`                  | 새 문자열 생성됨                  |
|            | `tuple` | 불변              | `(1, 2, 3)`                          | 내부에 가변형이 없을 때 완전 불변 |
| **가변형** | `list`  | 가변              | `[1, 2, 3].append(4)`                | 요소 추가, 삭제, 수정 가능        |
|            | `dict`  | 가변              | `d['key'] = 'value'`                 | 키-값 쌍 추가/변경 가능           |
|            | `set`   | 가변              | `s.add(10)`                          | 순서 없음, 중복 제거              |

**예시**

```python
# 불변형 예시
a = "hi"
print(id(a))     # 메모리 주소
a += " there"
print(id(a))     # 주소가 달라짐 → 불변형

# 가변형 예시
lst = [1, 2]
print(id(lst))   # 메모리 주소
lst.append(3)
print(id(lst))   # 주소 그대로 → 가변형
```

> 불변형: 값을 바꾸면 새 객체가 만들어짐  
> 가변형: 객체 자체를 직접 바꿀 수 있음 (메모리 주소 유지)

## 인덱싱과 슬라이싱

| 구분         | 설명                | 예시               | 결과        |
| ------------ | ------------------- | ------------------ | ----------- |
| **인덱싱**   | 하나만 선택         | `"apple"[1]`       | `'p'`       |
|              | 뒤에서 선택         | `"apple"[-1]`      | `'e'`       |
| **슬라이싱** | 시작\~끝-1까지 선택 | `"apple"[1:4]`     | `'ppl'`     |
|              | 시작 생략           | `"apple"[:3]`      | `'app'`     |
|              | 끝 생략             | `"apple"[2:]`      | `'ple'`     |
|              | 간격 사용           | `[1,2,3,4,5][::2]` | `[1, 3, 5]` |
|              | 역순                | `"abcde"[::-1]`    | `'edcba'`   |

1. - 인덱싱 : _"하나만 뽑기"_  
     리스트나 문자열에서 **하나의 요소를 꺼낼 때** 사용한다.

2. - 슬라이싱 : _"여러 개 잘라내기"_  
     시퀀스에서 범위를 지정해서 **부분 추출할 때** 사용한다.
